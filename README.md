### Track: 02 - Risk & Fraud Management

#### Problem
Merchants lose money to abuse rings: same IP doing 10 bulk orders in 5 mins + phishing messages.

#### Solution Built
- Real-time message scan with TF-IDF + Naive Bayes (Day 38 model)
- Trapping link detection (short URL + spam keyword heuristics)
- Abuse ring detection: Same IP burst >3 transactions in 5 mins

#### Tech Stack
Frontend: React + Vite
Backend: Python / FastAPI
ML: Scikit-learn TF-IDF
Deploy: Bolt.host

#### How to Run
1. Open Live Demo link
2. Paste suspicious message
3. See Risk Score + Flag
